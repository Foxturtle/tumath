# ⭐ 연산 연습 — 사용 설명서

초등학생이 **두 자리 수 덧셈·뺄셈**과 **구구단**을 연습하는 앱이에요.
종이 학습지처럼 **펜으로 직접 답을 쓰고**, 다 풀면 **부모님이 채점**해요.
글씨는 앱이 알아서 읽어 채점해 두기 때문에, 부모님은 확인만 하면 돼요.

- 문제는 풀 때마다 새로 만들어져서 **끝없이** 연습할 수 있어요.
- 한 번 설치하면 **인터넷이 없어도** 쓸 수 있어요.
- 돈이 들지 않고, 회원 가입도 필요 없어요.

> 앱 주소: **https://foxturtle.github.io/tumath/**

## 1. 준비물

- **태블릿이나 휴대폰** 중 하나
  - 갤럭시탭, 갤럭시 휴대폰 같은 **안드로이드** 기기
  - **아이패드, 아이폰**도 돼요
- **펜** (S펜, 애플 펜슬 등) — 있으면 좋아요. 없으면 손가락으로도 쓸 수 있어요.
- **인터넷** — 처음 설치할 때 한 번만 있으면 돼요.

> 💡 화면이 큰 **태블릿**을 추천해요. 답 쓰는 칸이 커서 아이가 쓰기 편해요.

## 2. 설치하기

설치는 **"홈 화면에 앱 아이콘 만들기"**예요. 플레이스토어나 앱스토어에서 받는 게 아니라, 인터넷 주소를 열어서 바로 설치해요.

### 갤럭시탭 · 갤럭시 휴대폰 (안드로이드)

1. **Chrome(크롬)** 앱을 열어요. (동그란 빨강·노랑·초록 아이콘)
2. 맨 위 주소 칸에 아래 주소를 입력하고 이동해요.
   **foxturtle.github.io/tumath**
3. 오른쪽 위 **⋮ (점 세 개)** 를 눌러요.
4. **"앱 설치"** 또는 **"홈 화면에 추가"** 를 눌러요.
   - "홈 화면에 추가"를 눌렀다면, 이어서 나오는 창에서 **"설치"** 를 골라요.
5. 이제 홈 화면이나 앱 목록에 **⭐ TU 별 아이콘**(이름: 연산 연습)이 생겨요.

> 💡 홈 화면에 아이콘이 안 보이면, 홈 화면을 **위로 쓸어 올려 앱 목록**을 보세요. 거기 있어요.
> 맨 위 검색 칸에 "연산"이라고 써서 찾아도 돼요.

### 아이패드 · 아이폰

1. **Safari(사파리)** 앱을 열어요. (파란 나침반 아이콘)
2. 주소 칸에 **foxturtle.github.io/tumath** 를 입력하고 이동해요.
3. 화면의 **공유 버튼 (네모에서 화살표가 위로 나온 모양 □↑)** 을 눌러요.
4. 아래로 내려서 **"홈 화면에 추가"** → 오른쪽 위 **"추가"** 를 눌러요.
5. 홈 화면에 **⭐ TU 별 아이콘**이 생겨요.

> ⚠️ 앞으로는 꼭 **홈 화면의 별 아이콘**으로 여세요.
> 인터넷(Chrome·Safari)에서 주소로 다시 열면, 아이가 푼 기록이 따로 저장돼서 이어지지 않아요.

## 3. 처음 한 번만 할 일

### ① 부모님 비밀번호 정하기

채점과 설정은 부모님만 할 수 있도록 **숫자 4자리 비밀번호**로 잠가요.

1. 앱을 열고 **시작하기 ▶** 를 눌러요.
2. 오른쪽 위 **⚙️ (톱니바퀴)** 를 눌러요.
3. **아이가 모르는 숫자 4자리**를 눌러요.
4. 확인을 위해 **같은 숫자를 한 번 더** 눌러요.

> ⚠️ 비밀번호는 꼭 기억해 두세요. 잊어버리면 기록을 모두 지워야 다시 정할 수 있어요.
> ([8. 이럴 땐 이렇게 하세요](#비밀번호를-잊어버렸어요) 참고)

### ② 아이 이름 바꾸기 (선택)

처음에는 이름이 **TU**로 되어 있어요. 시작 화면에 "TU만을 위한 연산 연습"처럼 나와요.

1. **⚙️ 부모님 메뉴**에서 **아이 이름** 옆의 **TU ✎** 를 눌러요.
2. 화면 아래 글자판으로 이름을 써요. **한글 / ABC** 버튼으로 바꿀 수 있어요. (6글자까지)
3. 오른쪽 위 **완료** 를 눌러요.

## 4. 문제 풀기 (아이)

### ① 무엇을 풀지 고르기

앱을 열면 별이 나오는 시작 화면이 보여요. **시작하기 ▶** 를 누르면 아래 4가지가 나와요.

| 버튼 | 내용 |
|---|---|
| **＋ 덧셈** | 두 자리 수 덧셈 (예: 47 + 65) |
| **－ 뺄셈** | 두 자리 수 뺄셈 (예: 62 − 27) |
| **× 곱셈** | 구구단 2단 ~ 9단 |
| **섞어 풀기** | 덧셈·뺄셈·곱셈을 한 번에 |

### ② 몇 문제 풀지 고르기

- **− / +** 버튼으로 10문제씩 줄이거나 늘려요. (**10문제 ~ 200문제**, 처음엔 20문제)
- **10 · 20 · 50 · 100 · 200** 버튼을 누르면 한 번에 바뀌어요.
- **곱셈**은 몇 단을 할지도 골라요. 여러 단을 고르면 섞여서 나와요. (**모두 고르기**도 있어요)
- **섞어 풀기**는 덧셈·뺄셈·곱셈을 각각 몇 문제 풀지 정해요. (모두 합쳐 200문제까지)
- 다 골랐으면 아래 **"○○문제 시작"** 을 눌러요.

> 💡 지난번에 고른 문제 수와 단을 기억해 둬요. 같은 걸 또 풀 땐 바로 시작만 누르면 돼요.

### ③ 답 쓰기

- 점선 네모 칸에 **펜으로 답을 써요.** 한 칸에 숫자 하나씩 써요.
- **세로셈**은 종이 학습지처럼 **오른쪽 칸(일의 자리)부터 자리를 맞춰** 써요.
- **가로셈**은 왼쪽 칸부터 써도 되고, 오른쪽에 맞춰 써도 돼요.
- **받아올림·받아내림 숫자**는 위의 빈 곳에 작게 써도 돼요. 채점할 때는 답 칸만 읽어요.

> 💡 처음 설정은 **펜으로만** 써져요. 손바닥이 화면에 닿아도 글씨가 안 써지게 하려고요.
> 펜이 없으면 [부모님 메뉴](#7-부모님-메뉴)에서 **"손가락으로도 쓰기"** 를 켜 주세요.

### ④ 화면 위의 버튼

| 버튼 | 하는 일 |
|---|---|
| ✏️ **펜** | 글씨 쓰기 (처음엔 이게 켜져 있어요) |
| 🧽 **지우개** | 지울 글씨 위를 문지르면 지워져요 |
| ↩️ **되돌리기** | 방금 쓴 것(또는 지운 것)을 취소해요 |
| 🏠 **처음으로** | 처음 화면으로 가요. 풀던 건 저장돼 있어요 |

> 💡 **갤럭시 S펜**은 **펜 옆 버튼을 누른 채** 문지르면 바로 지워져요.

### ⑤ 쪽 넘기기와 다 풀었을 때

- 한 쪽을 다 풀면 아래 **다음 ▶** 을 눌러요. 앞 쪽으로 가려면 **◀ 이전** 을 눌러요.
- 마지막 쪽에서 **다 풀었어요!** 를 눌러요.
  - 안 쓴 문제가 있으면 알려 줘요. **더 풀래요** 를 누르면 돌아가서 마저 풀 수 있어요.
- **부모님 채점하기** 를 누르면 부모님 비밀번호를 물어봐요.
  - 부모님이 바로 못 보면 **나중에** 를 눌러 두세요. 처음 화면에 "채점을 기다리는 학습지가 있어요"가 남아 있어요.

> 💡 풀다가 앱을 꺼도 괜찮아요. 다시 열면 처음 화면에 **"이어서 풀기"** 가 나와요.

## 5. 채점하기 (부모님)

1. 비밀번호 4자리를 누르면 **채점하기** 화면이 열려요.
2. 앱이 아이 글씨를 읽어서 **자동으로 채점해 둬요.** 잠깐 "글씨 읽는 중…"이 보일 수 있어요.
   - 맞은 문제: **빨간 동그라미 ○**
   - 틀린 문제와 빈칸: **빨간 빗금 ╱**

### 화면에 보이는 표시

| 표시 | 뜻 |
|---|---|
| **✎ 164** | 앱이 아이 글씨를 읽은 답 |
| **초록색 숫자** | 원래 정답 |
| **노란 테두리 칸** | 글씨가 애매해서 앱이 확실히 못 읽은 문제 → **꼭 확인해 주세요** |

### 빠르게 채점하는 방법 (추천)

1. 위쪽의 **틀린 것** 과 **노란 칸** 버튼을 **둘 다** 눌러요.
   → 틀렸거나 애매한 문제만 보여요. 나머지는 흐리게 보이거나 숨겨져요.
2. 보이는 문제의 **아이 글씨**와 **초록 정답**을 비교해요.
3. 채점이 잘못된 문제는 **그 문제를 한 번 눌러요.** ○ ↔ ╱ 가 바뀌어요.
4. 다 봤으면 오른쪽 위 **채점 완료** 를 눌러요.

> 💡 **전체** 버튼을 누르면 모든 문제가 다시 보여요.
> 💡 앱이 글씨를 잘못 읽을 때도 있어요. 특히 숫자를 붙여 쓰거나 칸 밖으로 크게 쓰면 그래요. 그래서 마지막 판단은 부모님이 해요.

## 6. 결과 보기와 틀린 문제 다시 풀기

- **채점 완료** 를 누르면 아이에게 **별 ⭐, 점수, 칭찬 한마디**가 나와요.
- 틀린 문제가 있으면 **"틀린 ○문제 다시 풀기"** 를 눌러 바로 다시 풀 수 있어요.
- 틀린 문제는 처음 화면의 **"틀린 문제 다시 풀기"** 에도 모여요.
  - 다시 풀어서 맞히면 목록에서 빠져요.

## 7. 부모님 메뉴

처음 화면 오른쪽 위 **⚙️** → 비밀번호 4자리를 누르면 열려요.

| 항목 | 설명 |
|---|---|
| **아이 이름** | 시작 화면과 처음 화면에 나오는 이름이에요 |
| **손가락으로도 쓰기** | 켜면 손가락으로도 글씨가 써져요. 펜을 쓴다면 꺼 두는 게 좋아요 (손바닥 닿음 방지) |
| **화면 돌리기 허용** | 끄면 화면이 **세로로 고정**돼요. 켜면 가로로도 돌아가요 |
| **풀이 시간 재기** | 켜면 다 푼 뒤 **걸린 시간**이 나와요. 푸는 동안에는 시간이 안 보여요 |
| **비밀번호 바꾸기** | 부모님 비밀번호를 새로 정해요 |
| **다시 풀기 목록 비우기** | 모아 둔 틀린 문제를 모두 지워요 |
| **기록** | 날짜별로 무엇을 풀었고 몇 점이었는지 보여요 |
| **앱 버전** | 맨 아래 숫자예요. 앱이 최신인지 확인할 때 써요 |

> 💡 **아이패드·아이폰**에서는 "화면 돌리기 허용"이 작동하지 않아요.
> 대신 화면 오른쪽 위를 쓸어내려 **제어 센터**를 열고, **자물쇠 모양(화면 회전 잠금)** 을 켜 주세요.

## 8. 이럴 땐 이렇게 하세요

### 새로 고친 내용이 안 보여요

앱이 **뒤에 켜진 채로** 남아 있으면 예전 모습 그대로예요.

1. 화면 아래 **최근 앱 보기 버튼(☰ 또는 □)** 을 눌러요.
   (버튼이 없으면 화면 아래에서 위로 천천히 쓸어 올려요)
2. **연산 연습**을 **위로 밀어서 완전히 닫아요.**
3. **인터넷이 연결된 상태로** 다시 열어요.
4. **⚙️ 부모님 메뉴** 맨 아래 **앱 버전**이 바뀌었는지 확인해요.

### 앱 아이콘이 예전 모양이에요

아이콘은 휴대폰·태블릿이 **하루 이틀 뒤에 알아서** 바꿔요. 기다리면 돼요.
바로 바꾸고 싶다면 앱을 지우고 다시 설치하세요. 이때 아래 내용을 꼭 지켜 주세요.

> ⚠️ 앱을 지울 때 **"데이터도 삭제"** 같은 선택이 나오면 **고르지 마세요.**
> 고르면 아이의 기록과 비밀번호가 모두 지워져요.

### 글씨가 안 써져요

- 처음 설정은 **펜으로만** 써져요. 손가락으로 쓰려면 **⚙️ 부모님 메뉴 → 손가락으로도 쓰기**를 켜 주세요.
- 위쪽 버튼 중 🧽 **지우개**가 켜져 있으면 써지지 않아요. ✏️ **펜**을 눌러 주세요.

### 채점이 틀렸어요

채점하기 화면에서 **그 문제를 한 번 누르면** ○ ↔ ╱ 가 바뀌어요.
**채점 완료**를 누르기 전에 고쳐 주세요.

### 인터넷이 없어도 되나요?

네. 한 번 설치해서 열어 봤다면 **인터넷 없이도** 문제 풀기와 채점이 모두 돼요.
다만 새로 고친 내용은 인터넷이 연결됐을 때 받아요.

### 아이 기록은 어디에 저장되나요?

**그 태블릿(휴대폰) 안에만** 저장돼요. 인터넷으로 어디에 보내지 않아요.
그래서 **다른 기기와 기록이 이어지지 않아요.** 태블릿과 휴대폰을 둘 다 쓰면 기록이 따로따로예요.

### 비밀번호를 잊어버렸어요

비밀번호를 찾는 방법은 없어요. **앱에 저장된 내용을 모두 지우고** 새로 시작해야 해요.
(아이의 기록, 틀린 문제 목록도 함께 지워져요)

- **안드로이드:** Chrome → 오른쪽 위 ⋮ → **설정** → **사이트 설정** → **모든 사이트** →
  **foxturtle.github.io** → **삭제(지우기)**
- **아이패드·아이폰:** 홈 화면의 별 아이콘을 길게 눌러 **앱 삭제** → 다시 설치

그다음 앱을 열면 비밀번호를 새로 정할 수 있어요.

### 문제 수를 많이 고르면 느려지나요?

200문제까지 괜찮아요. 채점할 때 "글씨 읽는 중…"이 몇 초 보일 수 있어요.
